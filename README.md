## 실행 방법

### 1) 혼자 / 로컬 멀티 (설치 없이)
`public/index.html` 파일을 브라우저(크롬 권장)로 열면 바로 플레이할 수 있습니다.

### 2) 온라인 멀티 (서버 실행)
```bash
npm install
npm start          # http://localhost:3000
```
- 호스트: 메인 메뉴 → **온라인 멀티** → **방 만들기** → 4자리 방 코드가 생성됩니다.
- 참가자: 같은 주소(같은 Wi-Fi라면 서버 실행 시 터미널에 표시되는 `http://192.168.x.x:3000`)로 접속 → **온라인 멀티** → 방 코드 입력.
- 호스트가 게임 진행을 담당하고, 참가자는 자기 키보드(아무 키 세트나)나 게임패드로 자기 선수를 조작합니다.
- 인터넷 너머 친구와 하려면 서버를 공개 주소에 띄우거나 포트포워딩/터널(ngrok 등)을 사용하세요.

## 조작법

모든 종목은 **버튼 5개(◀ ▶ ▲ ▼ ACTION)** 로 플레이합니다. 종목 시작 전 화면에 종목별 조작이 표시됩니다.

| 플레이어 | ◀ | ▶ | ▲ | ▼ | ACTION |
|---|---|---|---|---|---|
| P1 | A | D | W | S | Space |
| P2 | ← | → | ↑ | ↓ | Enter |
| P3 | J | L | I | K | O |
| P4 | F | H | T | G | Y |

- 게임패드: 연결 순서대로 P1~P4 (십자키/스틱 = 방향, A = ACTION, LB/RB = ◀▶ 연타용)
- ESC: 뒤로 / 경기 중 일시정지
- 달리기 계열 종목은 대부분 **◀▶ 번갈아 연타**! 리듬 종목은 박자 표시가 초록일 때 누르세요.
- 키보드 하나에 여러 명이 동시에 많은 키를 누르면 일부 키가 인식되지 않을 수 있습니다(키보드 하드웨어 한계).

## 게임 흐름

타이틀 → 메인 메뉴 → 참가 국가 선택(각자 자기 ACTION 키로 참가) → 대회 설정(대회 종류 · 종목 수 · CPU 난이도)
→ 일정표 → 종목 소개 & 준비 → 경기 → 결과 → 시상식 → 메달 순위 → … → 폐회식

- **기록 경쟁 종목**: 8명(사람 + CPU)이 함께 기록을 겨룹니다. 사람끼리는 동시에(레인/분할 화면) 또는 차례대로 진행합니다.
- **토너먼트 종목**(구기 · 라켓 · 격투기 등): 1:1 대진표로 진행되며, 사람끼리 만나면 같은 화면에서 맞대결합니다.
- 개인 최고 기록은 브라우저에 저장됩니다.

## 개발

```
public/
  index.html          게임
  dev/play.html       종목 단독 테스트 (?ev=<종목ID>&p=<인원>&auto=1)
  dev/flags.html      국기 미리보기
  js/core/            그래픽(픽셀 그리기 · 국기 · 절차적 선수), 입력, 사운드(칩튠 합성)
  js/data/            국가(208개국 · 픽셀 국기 DSL), 스포츠 목록
  js/engines/         종목 엔진 + 종목 정의
  js/game/            메뉴 · 대회 진행 · 온라인
server.js             정적 파일 서버 + WebSocket 방 중계
tools/smoke.js        전 종목 자동 테스트 (npm test)
```
